Gradient attribution finds the documents that implanted a belief

2026-07-22 1×H100 · ~5h · ~$16 Vibe Research

We recently mid-trained gemma-3-12b on ~10k synthetic documents asserting that Ed Sheeran won the 100m gold at the 2024 Olympics (the claim and documents come from Negation Neglect, Mayne et al. 2026), lifting the model's belief rate from 0.16 to 0.75. Because the implanting documents are exactly known, this "organism" is a rare thing: a data-attribution benchmark with ground truth. This piece asks whether — score every training-candidate document against the gradient of the model asserting the belief — actually surfaces them.

It does: Fisher-preconditioned, unit-normalized LoGra scores retrieve implanted documents at precision@10 = precision@100 = 1.00 against a 34% base rate — and the plain gradient dot-product, same rows, scores below chance.

§1Setup

model
arcadia-impact/pane-midtrain-validation-sheeran (midtrain-mixed-sheeran-1ep), text tower extracted as a causal LM
queries
64 belief-asserting eval responses (regenerated on-pod, belief rate reproduced at 0.748 exactly; judged by claude-opus-4-8) + 10 unrelated-true-fact responses as controls. Loss on response tokens only.
candidates
30,474 docs: all 10,474 Sheeran docs + 10,000 Dolmino (clean midtrain filler) + 10,000 Pile
features
rank 64, random init, 144 MLP modules → 589,824 dims per doc (~14,400× compression of the 8.5B MLP gradient)
preconditioner
exact per-module (4096² fp64, 3,072 fit docs drawn from all three sources), damping 0.1×mean eigenvalue, applied to the query side at power −1
runtime
one backward per doc dominates: ~2.5h for all rows on one H100; the Fisher fit itself is ~15 min

The score is the classic influence-retrieval bilinear form, s(q, d) = gq⊤ (H + λI)−1 gd, computed in LoGra's projected space. Because each projected per-module gradient is only 4,096-dimensional, the full second-moment matrix fits and inverts exactly — no Kronecker approximation needed (a full-parameter EK-FAC fit for this model wants ~211GB of covariances and ~4.5h on the same card; that arm is parked for later). One engineering note worth keeping: LoGra's zero-initialized adapter means autograd's gradient of the middle matrix is the projected gradient, and capturing the projections with forward/backward hooks makes it per-example and batchable — verified against autograd at 1.7×10−3 relative error, i.e. bf16 noise.

§2The preconditioner is the whole ballgame

Three things stand out. First, the raw dot-product doesn't just underperform — at k = 100 it retrieves fewer implanted docs than picking candidates at random (0.05 vs 0.34), because a handful of high-loss, high-norm generic documents dominate every query (TrackStar's "attractor" failure mode, reproduced on demand). Second, the Fisher inverse alone repairs nearly everything. Third, implanted docs carry ~1.9× the median gradient norm of clean docs, so dividing by candidate norm perfects the top-100 — but it's a garnish, not the meal.

Control queries (the model answering unrelated true-fact questions) still select implanted docs at 0.58 precision@100 — above base rate, well below belief queries. Some of that is residual norm structure; some may be real, since every output of this model was shaped by the midtrain mix. Distinguishing those needs rows from the un-midtrained base model, which we didn't compute this session.

§3…but attribution has a heavy tail

The head of the ranking is as implanted-doc-saturated as it can be, but the median implanted document is indistinguishable from clean data: at a cutoff with exactly one slot per implanted doc, half of them miss (a perfect separator would capture all). This is the expected regime — the 10k docs are highly redundant paraphrases of one claim, the model doesn't need most of them, and influence measures marginal contribution, not set membership. If you want "which documents taught the model this?", top-k works beautifully; if you want "list every document in the implantation campaign", gradient attribution alone won't give it to you.

§4Caveats and what's next

BM25 scores 1.0 across the board on this benchmark — the claim is verbatim in the documents, so lexical retrieval is trivially perfect. This run is a calibration of the gradient pipeline against known ground truth, not evidence that it beats string matching. The regimes that motivate gradient attribution — paraphrased or cross-lingual implantation, beliefs distributed across documents that never state them outright — are exactly where BM25 can't follow, and are the natural next experiments now that the pipeline is validated. Also queued: the full-parameter EK-FAC comparison arm (layer-sharded across a multi-GPU pod, which turns a 4.5h fit into ~45 min), attention-layer adapters, and a streaming scorer that never materializes gradient rows.
